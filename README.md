### 🔒 [DenseZK — Parallel Proof Generation](https://github.com/hushnetlabs/dense-zkvm)
> GSSoC 2026 Open Source Contribution

- Parallelized ZK proof generation in Flutter mobile app
- Built `ConnectionLimiter` (semaphore pattern) for concurrent HTTP requests
- Added `createWitnessBatch()` for parallel witness processing
- Added `_withRetry()` for partial failure handling with exponential backoff
- Benchmark: `runConcurrencyBenchmark()` testing 1, 2, 4, 8 concurrent connections
- Result: measurable speedup over sequential proof generation
